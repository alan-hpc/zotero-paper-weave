# PaperWeave 0.1.0-alpha.46 · 任务恢复、单词边界与公式字形

适用于 Zotero 10，Alpha 预览版。

修复截图阶段报 `can't access property "AbortController", host.getMainWindow() is null` 的问题。断网期间暴露出的直接故障是：工作台仍打开，但 Zotero 文库主窗口已不可用，截图任务仍尝试从该窗口创建控制器。

- 任务控制器和插件内置字体读取改用应用级环境，不再依赖文库主窗口。
- 原文阅读器关闭或失效后，按工作台绑定的原 PDF 重新连接；主窗口不存在时使用 Zotero 的独立阅读窗口。也覆盖选择未加载标签页时主窗口刚好关闭的情况。
- 工作台入口与窗口创建处理主窗口缺失的情况，继续使用单窗口和论文身份校验。截图仍有限重试，取消后释放渲染资源。
- 修复正文与等宽 API 名称零间隙连接的问题，例如 `ThencclEpGroup_tman ages` 和 `whilencclEpHandle_tcap tures`。依据字形和断行信息恢复 `The ncclEpGroup_t manages`、`while ncclEpHandle_t captures`，标识符内部保持完整。
- 恢复小型大写标题的词间边界，例如 `COMPARISON OF HT AND LL KERNEL MODES`。旧译文中的 `LLKERNEL` 等残留会进入复核，人工修订不自动覆盖。只对源文等价、坐标一致的缓存迁移，已有识别结果和对应译文继续保留。
- 修复 LaTeX 转 PDF 时平滑曲线的控制点错误，将公式轮廓精确转换为三次曲线后绘制，消除括号、字母和符号的尖刺、拖影。公式内容、尺寸和矢量输出保留，无需修改 LaTeX 或更换字体。
- 已保存译文、人工修订和恢复句组继续保留。PDF 生成前的识别与保护校验保持不变，未解决的问题仍需核对。
- 无需修改 Codex、DeepSeek 或兼容 API 配置，无需更新代理。

安装并重启 Zotero 后，打开同一论文的 PaperWeave 工作台，网络恢复后点击“翻译并生成 PDF”，即可复用已保存进度继续。不要清除项目缓存或删除旧译文。

单词黏连已进入旧译文的段落，需要使用“重译需复核段落（保留人工修订）”后重新生成。仅有公式轮廓破损时，复用已有译文重新生成即可，无需重复图片识别。

已通过类型检查、完整离线回归与安装包检查，覆盖无主窗口截图、阅读器重连、未加载标签页竞态、取消清理、字体跨环境字节复制、工作台窗口创建、单词边界、OCR 保留和曲线几何。已在 NCCL EP 项目副本中验证 284 个段落的安全迁移，保留全部 204 段译文及 7 个已采用识别层，并实际生成、目检 b121/b122 的公式 PDF。未调用真实模型，未修改正在使用的项目缓存，尚未在 Zotero 内安装验收。

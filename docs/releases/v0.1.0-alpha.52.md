# PaperWeave 0.1.0-alpha.52 · 全文重译并生成 PDF

适用于 Zotero 10。安装 XPI 并重启后，原主按钮旁新增「重新翻译并生成 PDF」。

- 「翻译并生成 PDF」继续复用已有译文。
- 「重新翻译并生成 PDF」按当前模型配置重新翻译正文和标题的自动译文，保留人工修订、现有术语表和原文区域；新稿通过校验后逐段替换旧文。
- 中断后显示「继续重译并生成 PDF」，仅续跑剩余段落；原主按钮也能继续该任务。修改模型、偏好、词表或原文结构会重新开始一轮。
- 完成翻译与自动检查后，更新同一个 PDF 附件。生成或保存失败保留旧 PDF，重试无需重译已完成段落；成功后再点击重译按钮才开始新一轮。

人工修订若需覆盖，可选择该段使用「重新翻译本段（覆盖）」。

本版不更改用户的默认模型，不需要更新代理。沿用 alpha.51 的单一阅读副本、失败回滚和公式空格修复。

验证包含完整类型/回归/构建检查与真实 PDF 输出。未在当前 Zotero 安装新版或启动整篇付费重译。

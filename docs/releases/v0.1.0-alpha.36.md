# PaperWeave 0.1.0-alpha.36 · 工作台单例修复

适用于 **Zotero 10**，早期预览版。

## 本次修复

修复工作台仍在打开、页面卸载事件却提前清除窗口记录，下一次点击又创建窗口的问题。现在会查找 Zotero 中已有的 PaperWeave 工作台，并在多个主窗口及控制器之间共享打开状态。

- 重复点击入口会恢复、聚焦已有工作台，保留当前论文与翻译任务。
- 临时无法读取窗口状态时保留占用；确认窗口已关闭后，才允许打开另一篇。
- 识别未被当前控制器记录的旧窗口；插件关闭时一并尝试保存项目。
- 保留 alpha.35 的 DeepSeek 单独使用与自上而下 API 优先级设置。

## 使用

下载 `paperweave-0.1.0-alpha.36.xpi`，在 Zotero「工具 → 插件 → 齿轮 → 从文件安装插件」中更新。**建议先保存修订，待当前翻译任务结束后更新并重启 Zotero**，再连续点击相同或不同论文的入口检查窗口复用。已有译文、术语表与模型 Key 保留。

[使用说明](https://github.com/alan-hpc/zotero-paper-weave#readme) · [问题反馈](https://github.com/alan-hpc/zotero-paper-weave/issues)

## 验证状态

新增回归先在旧代码上复现重复开窗，再验证初始化文档卸载、暂时失效的窗口引用、实际窗口查找、独立控制器并发、关闭重开、失效引用和原生打开失败。通过类型检查、完整离线回归与构建。

没有调用真实翻译模型，本安装包尚未在 Zotero 中安装验收。版面与数学识别仍需对照原文复核；旧 PDF 批注不会自动迁移，修订项目需自行备份。Alpha 更新需手动安装。

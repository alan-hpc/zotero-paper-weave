# PaperWeave 0.1.0-alpha.35 · 服务优先级

适用于 **Zotero 10**，这是早期预览版。

## 本次变化

- **只用 DeepSeek 即可**：仅启用 DeepSeek、填写地址/模型/Key，Codex 和其他 API 可停用、留空。
- 按配置面板**从上到下的优先级**调用服务。每项可「上移 / 下移」并保存顺序，未启用或配置不完整的项会跳过，界面显示实际顺序及原因。
- 开启「额度耗尽时按顺序切换到下一可用服务」后，仅在明确的额度/余额耗尽时顺序切换；并行请求共享切换状态，后续请求沿用新服务，下次任务重新从顶部开始。
- 临时限速、普通排队、网络、登录及内容校验错误保留原处理方式。没有后续可用服务时保留进度并停止。
- 旧版按原首选服务迁移，Key 继续按端点保存在 Zotero 凭据管理器，已有译文与修订保留。

## 安装与使用

下载 `paperweave-0.1.0-alpha.35.xpi`，通过 Zotero「工具 → 插件 → 齿轮 → 从文件安装插件」安装并重启。右键论文或 PDF 打开 PaperWeave，在「模型与翻译偏好」中设置服务，点击「保存全部设置」。Alpha 更新需手动安装。

DeepSeek 地址 `https://api.deepseek.com/v1`，模型填写账户可用的 ID（例如 `deepseek-flash`），填入 API Key 即可。可选 Codex 代理的脚本与说明文件也在本发布页；仅用 DeepSeek 时无需下载或运行代理。

## 验证与限制

通过类型检查、离线回归与构建，覆盖 DeepSeek 单服务、空配置跳过、顺序保存与恢复、三服务并行额度切换和凭据隔离。测试使用模拟响应，没有发起真实模型调用，也未安装到 Zotero 验收。

继续提供原文左侧 60% / 中文右侧 40% 的可修订 PDF。版面与数学识别可能出错，需对照原文复核；旧 PDF 批注不会自动迁移，修订项目需自行导出备份。扫描件需先 OCR，加密或旋转页暂不支持。

翻译或切换服务会向对应模型发送论文文本，并可能计费，不上传 PDF 文件或图片。详见[隐私说明](https://github.com/alan-hpc/zotero-paper-weave/blob/main/docs/PRIVACY.md)。本项目独立开发，与 Zotero 官方无隶属关系。

# PaperWeave 0.1.0-alpha.50 · 保留中文的自动恢复

适用于 Zotero 10，Alpha 预览版。无需逐段人工确认。

安装 XPI 并重启后，保留现有配置，启用自动检查并点击「翻译并生成 PDF」。仅用 DeepSeek 无需本机代理；Codex 用户需同步更新包内代理脚本并重启，地址、模型和登录无需重填。

1. 先核验现有中文及公式出现位置，正确的文字直接复用。
2. 可靠的原公式区域直接嵌入对应中文；截图不能完整隔离时，仅识别该公式并进行第二次原图核验，通过后只修复这一处显示。
3. 中文确实有问题才依据原图重新翻译，再独立检查。未通过的新稿不覆盖旧中文。
4. 核验按批保存，包括候选草稿；中断后只处理剩余部分，来源/文字/几何/配置不匹配时不使用旧进度。
5. 检查 PDF 正文区域、版面边界与各公式次数后才添加附件。最终确实无法恢复的正文明确保留原文，服务或来源错误不会被标为内容完成。

包含短段落干扰公式编号裁切宽度、函数名与数学参数跨行的问题修复。图片请求不跨服务回退，原始 PDF、既有人工修订和旧附件保留。

验证：完整类型/回归/构建检查，覆盖真实 PDF 输出、缓存中文复用、单公式识别和二次核验、拒绝未通过结果、恢复草稿及批次、取消/网络错误、来源隔离、公式位置次数和代理新任务。DistMoE 隔离副本的 501 个区域已有中文均未改写；b59 的 14 处数学表达完成处理（13 处原字形与 1 处经过二次核验的 LaTeX），完整输出 56 页 PDF；已检查该段、续页及完整算法版面，重复生成零模型请求。未修改 Zotero 现有项目缓存和原附件；尚未安装本版到当前 Zotero。

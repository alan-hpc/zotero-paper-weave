# PaperWeave 0.1.0-alpha.41 · 主流程图片复核与摘要误判修复

适用于 Zotero 10，早期预览版。

- 修复 PDF 提取出的 `https: //…` 链接被误当数学表达，导致已有中文摘要被整段英文原图替代的问题；识别 `1.65×` 时保留完整倍率符号。
- 更新兼容缓存的数学信息，保留已有中文、人工修订和原始 PDF，无需为了修复链接误判而重译整篇论文。
- 主按钮下新增可见的“生成 PDF 前，自动用 DeepSeek 图片识别需复核段落”选项，默认关闭。开启后，“翻译并生成 PDF”先修复需复核的自动译文，再导出；复用已有 DeepSeek 配置。
- 仍有疑问时停在核对区，不生成另一个未修复的 PDF。核对并采用识别结果后，再点主按钮继续重译和生成。人工修订不被自动覆盖。

完整说明：[DeepSeek 图片识别](https://github.com/alan-hpc/zotero-paper-weave/blob/main/docs/VISION.zh-CN.md)。开启图片复核会上传目标段落截图，并产生 DeepSeek API 用量；图片请求不跨服务回退。

离线回归覆盖链接与倍率、缓存迁移、主按钮完整流程、不确定结果、采用后继续、人工修订保护。未在 Zotero 内安装本版，未调用真实 DeepSeek。

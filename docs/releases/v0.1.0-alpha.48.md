# PaperWeave 0.1.0-alpha.48 · 失败句组逐句恢复

适用于 Zotero 10，Alpha 预览版，包含之前版本的修复。

修复 DistMoE b232 这类“图片识别已采用，但一个长句组中的公式引用反复重复，导致最后一段无法保存”的恢复问题。

- 原有整段、句组恢复仍保留。某个句组反复失败时，只将该组拆成完整句子逐句翻译，附带全文语境；成功的其他句组复用。
- 逐句结果保存在独立、来源和配置绑定的进度中，失败、取消或重启后继续剩余句子；恢复时不会先清空已成功的句子。只有整段完整校验通过后才替换旧译文。
- 相同公式的各次出现仍是不同引用。提示模型正确翻译代词而不增加公式；逐句、句组合并和整段合并均检查遗漏、重复、外来引用、字面值重复及加粗结构。不通过删除多出的公式或放宽检查来生成 PDF。
- 支持 `Tab.`/`Tabs.` 缩写边界；不拆开公式、代码、括号和加粗范围。每个失败句组最多 32 句，每句最多两个响应。单句仍失败时明确停止并保留进度。
- 状态和编辑区显示实际缺失、重复与未知数量，以及失败的父句组和句子位置。已采用识别继续使用，无需重新上传同一截图。

安装并重启 Zotero 后，打开同一 DistMoE 项目，再点击“翻译并生成 PDF”。已完成的 312 段保留，b232 会进入逐句恢复；之后继续原有识别复核与 PDF 生成流程。无需清空缓存、重设模型或更新代理。

已通过类型检查、完整离线回归与打包。在隔离项目副本中，用当前本机 Codex `gpt-6-luna` 完成 b232：第 1 组 5 句、第 2 组一次，共 6 次文字请求，4 处损失公式及保护项全部通过，其他段落未变；该段 PDF 排版验证通过。整篇仍有其他数学复核项，尚未在 Zotero 安装或声称整篇已导出；原项目缓存未修改。

# PaperWeave 0.1.0-alpha.51 · 单一阅读副本

适用于 Zotero 10，Alpha 预览版。安装 XPI 并重启后，重新点击「翻译并生成 PDF」即可。模型配置、已有中文、人工修订与核验进度继续保留。

- 首次生成添加附件；以后覆盖同一个附件和文件，保留名称、编号与批注记录。同一论文条目下不同原 PDF 修订版共用这个阅读副本；独立 PDF 各自保留一个。
- 已有多个译本时，优先保留当前首选的 PaperWeave 译本，否则保留最新附件。新文件与项目记录保存成功后，其他有来源记录的译本移入 Zotero 回收站，保留其批注。原始 PDF 与其他附件不动。
- 生成失败时恢复旧阅读副本；缺失文件可在原附件下恢复。并发生成串行保存；清理失败会提示再次生成以重试。
- 修复正常 TeX 空格触发「LaTeX 字形路径为空」。保留原有间距和可见字形校验；真正无效的自动公式在排版前进入原有修复流程。

同一附件上的批注记录会保留，版面重排后的坐标不会自动调整；历史重复附件的批注不自动合并。

本版无需变更当前代理或模型。若从 alpha.49 或更早版本升级，使用 Codex 图片自动恢复仍需 alpha.50 或更新的配套代理。

验证：真实 PDF 文件覆盖、批注与编号保持、故障回滚、来源隔离、重复清理重试、缺失文件与并发生成；SonicMoE 的 502 个区域使用已有中文，零模型请求生成 61 页 PDF，检查两处原报错段落。未修改 Zotero 现有缓存或附件；尚未安装本版进行原生验收。

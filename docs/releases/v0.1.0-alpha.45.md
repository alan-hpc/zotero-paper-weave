# PaperWeave 0.1.0-alpha.45 · 翻译保护与恢复机制

适用于 Zotero 10，Alpha 预览版。

- 保护校验反复失败时，按完整句子启用来源绑定恢复：模型收到可读短引用及其原文含义，插件本地还原公式和术语，并进行句组与整段双重校验。
- 修复同栏正文行末截图缺字，更新跨页续句与图号引用的识别规则；旧版未解决的识别使用新范围重试，已采用与人工修订结果保留。
- 保存已通过的恢复句组，取消、失败或重启后继续剩余部分；原文、格式、词表或配置变化时重新核对绑定，不混用旧进度。
- 区分识别错误与翻译保护错误。识别已采用时复用现有结果，显示失败句组及恢复进度，避免反复上传同一截图。
- 整段全部通过才替换旧译文；严格的 PDF 生成拦截、人工修订、源 PDF 和旧附件均保留。
- 复用现有 Codex、DeepSeek 和兼容 API 配置；无需更新代理或新增 Key。

完整方案见 [翻译保护、错误恢复与验收](../TRANSLATION_RECOVERY.zh-CN.md)。

安装并重启 Zotero 后，打开原论文，继续“翻译并生成 PDF”。已保存的自动译文和人工修订继续保留；旧版失败状态会进入新恢复路径。

# PaperWeave 0.1.0-alpha.34 · 早期预览版

适用于 **Zotero 10**。把英文论文生成左侧完整原页 60%、右侧中文 40% 的对照 PDF；译文可在工作台逐段修订、保存并重新生成。译文较长时增加续页，按原文页和段落组织。

## 下载与使用

1. 下载 `paperweave-0.1.0-alpha.34.xpi`，在 Zotero「工具 → 插件 → 齿轮 → 从文件安装插件」中安装并重启。
2. 选中论文或 PDF，右键打开「PaperWeave · 逐段双语 PDF / 修订」，填写并保存模型设置。
3. 点击「翻译并生成 PDF」。生成的新附件默认作为这篇论文优先打开的 PDF，原附件保留。

[使用说明](https://github.com/alan-hpc/zotero-paper-weave#readme) · [问题反馈](https://github.com/alan-hpc/zotero-paper-weave/issues)

## 相比上一公开安装包 alpha.14

- 保留左侧完整原页，右栏放置中文和对应的原文图表、图注、表格及公式；技术术语逐篇识别，可手工调整。
- 改进数学表达保护、源译对应、图表裁切、列表和加粗排版；支持手工 LaTeX 离线渲染。不确定的数学对应保留原文并提示复核。
- 增加有上限的并行翻译、失败重试和进度说明。再次执行会复用已保存译文；人工修订可保存并重新生成 PDF。
- 支持可选本机 Codex 代理，Codex 与 DeepSeek 分别保存配置；可选择在 Codex 明确报告额度耗尽时切换 DeepSeek。临时限速或连接错误不触发此切换。
- 仅打开一个工作台。新附件名称使用「论文名字__日期时间」。
- 本版将作者、单位、邮箱和通讯作者说明保留在左侧，跳过右栏翻译和重排，保留旧缓存及人工修订。

## 可选 Codex 代理

同时下载 `paperweave-codex-proxy.mjs` 和 `CODEX_PROXY.zh-CN.md`。需要 Node.js 20.10+、官方 Codex CLI 的 ChatGPT 登录，并在翻译期间保持代理运行：

```sh
node /你的下载目录/paperweave-codex-proxy.mjs
```

插件地址填 `http://127.0.0.1:47771/v1`，模型填 `codex-local` 或账户可用的具体模型 ID，Key 留空。该任务不继承当前聊天，模型权限和额度取决于账户。

## 验证与限制

类型检查、离线回归与构建通过。alpha.34 用 SASS 论文缓存完成 7 页原文到 19 页对照 PDF 的重排；此前在 macOS / Zotero 10 完成过少量 DeepSeek 翻译、修订和首选附件检查，以及 Codex 代理短句真实调用。额度切换使用模拟错误验证。

**此 alpha.34 安装包尚未在 Zotero 内完成安装验收，其他平台尚未验证。** 版面分类、图表范围及数学对应可能出错，需对照原文复核；扫描件需先 OCR，加密或旋转页暂不支持。旧 PDF 批注不会自动迁移，修订项目保存在本机，需自行导出备份。Alpha 更新需手动安装。

翻译会向所选服务发送论文文本，可能计费；不上传 PDF 文件或图片。详见[隐私说明](https://github.com/alan-hpc/zotero-paper-weave/blob/main/docs/PRIVACY.md)。本项目独立开发，未获 Zotero 官方认证。

# PaperWeave 0.1.0-alpha.53 · 阅读工作台

适用于 Zotero 10。安装 XPI 并重启后，工作台采用方案 2 的三栏布局：

- 左侧段落列表，中间原 PDF 整页，右侧可编辑中文；底部保留生成、全文重译与任务进度。
- 点击段落会自动切页、滚动并高亮对应原文，右侧同步显示译文。跨页段落先看起始页，可前后翻页；支持适合宽度、150% 和 200% 缩放。
- 原文预览仅在本机渲染，不请求模型、不上传整页，不改变导出流程。同页复用预览，最多缓存三页；快速切段或切换论文时旧回调不会覆盖新页面。
- 模型设置统一为模型 1 / 2 / 3，每项可填写任意兼容 API、模型 ID 与 Key；按从上到下的优先级调用，也可设置同一服务的不同模型。
- 有可用配置时设置默认收起，没有可用配置时自动展开。一次只展开一个模型的详细字段，偏好与代理工具收在设置内。
- 原有地址、模型、顺序、Key 与译文继续保留。新 Key 按配置项和地址独立保存，删除某项不会删除其他项或恢复旧 Key。

沿用全文重译断点恢复、人工修订保护和同一 PDF 更新。无需更新或重启配套代理。本版尚未安装到当前 Zotero；已通过类型、回归与构建检查，原生 Zotero 实际渲染仍需安装后验收。

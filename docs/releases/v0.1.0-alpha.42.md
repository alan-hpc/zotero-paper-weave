# PaperWeave 0.1.0-alpha.42 · 截图跨窗口字节复制修复

适用于 Zotero 10，早期预览版。

- 修复图片识别操作中的 `Accessing TypedArray data over Xrays` 错误：图像字节先复制到当前运行环境，再读取或编码。
- 同时覆盖首次截图、缓存读取与保存、原始 PDF、内置字体、工作台传递和生成附件的字节边界。
- 原文、保存的译文、人工修订和 API 配置继续保留；截图上传仍由原有选项控制。
- 安装后重启 Zotero，重新打开论文，再点击“图片识别本段”或启用图片复核后点击“翻译并生成 PDF”。不需要重新填写 Key。

离线检查复现旧的二进制读取错误，并覆盖跨 JavaScript 环境复制、缓存复用、字体失败结束和工作台生成真实 PDF。尚未在 Zotero 内安装本版，也未调用真实 DeepSeek。

# PaperWeave 0.1.0-alpha.38 · 论文切换与项目隔离

适用于 **Zotero 10**，早期预览版。

## 修复与使用

- 库内右键按所选论文打开，阅读器按钮按其所属 PDF 打开，避免误取另一个标签页。
- 工作台空闲时，打开 B 会先保存 A 的修订，再切换到 B，始终只保留一个工作台。
- A 正在翻译或载入时，继续保留 A，并提示先等待或取消；保存失败时也保留 A。
- 相同论文重复点击只聚焦；快速连续请求以最后一次有效目标为准。每次切换使用独立会话，避免旧参数或延迟回调串到另一篇。
- 工作台和窗口标题显示实际论文名称。缓存载入、保存及 PDF 生成增加来源校验，不匹配时停止并保留原项目。

更新 `paperweave-0.1.0-alpha.38.xpi` 后重启 Zotero，再打开目标论文。已有译文、术语与模型设置保留。

## 验证

类型检查与完整离线回归覆盖 ReplaySSM/Linear 切换、任务保护、保存失败、快速切换、原文/生成附件、同哈希不同条目和跨论文写入拦截。相关本机缓存首页与原附件、生成附件父条目检查一致；这个样本内未发现跨论文缓存覆盖。

原生 Zotero 安装与切换验证将在发布前补充。版面和公式识别仍需复核；修订项目请自行导出备份，旧 PDF 批注不会自动迁移。

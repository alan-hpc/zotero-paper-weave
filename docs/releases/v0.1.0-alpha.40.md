# PaperWeave 0.1.0-alpha.40 · DeepSeek 图片识别

适用于 Zotero 10，早期预览版。

- 复用已有 DeepSeek 地址、Key 和 `deepseek-flash`，识别疑难正文截图中的英文和 LaTeX。
- 在编辑区展开“DeepSeek 图片识别与原图核对”：本地查看截图、请求识别、修订识别原文、核对采用，再重新翻译本段。识别本身不覆盖旧译文。
- 可选批量流程：启用“重译需复核段落前，先用 DeepSeek 图片识别”，再点击“重译需复核段落（保留人工修订）”。默认不会自动上传图片。
- 截图和识别结果缓存；原始提取、人工修订及旧 PDF 保留。图片请求不跨服务回退；有疑问、数字/区域类型变化或无效结果保留待核对。

完整说明：[DeepSeek 图片识别](https://github.com/alan-hpc/zotero-paper-weave/blob/main/docs/VISION.zh-CN.md)。可选图片识别会将目标段落 PNG 发送至配置的 DeepSeek 服务，并产生额外 API 用量。

类型检查和完整离线回归通过，覆盖多模态请求、PNG 缓存、来源校验、识别修订/采用、批量流程、取消、失败保留及识别源文 LaTeX 的 PDF 排版。尚未在 Zotero 内安装验收，也未调用真实 DeepSeek 验证识别准确率。

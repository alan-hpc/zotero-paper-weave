# PaperWeave 0.1.0-alpha.43 · 跟随当前模型识别图片

适用于 Zotero 10，早期预览版。

- 自动图片复核与单段图片识别都跟随当前启用的模型和服务优先级，不再固定调用 DeepSeek。
- Codex 排在前面时，更新后的本机代理将目标 PNG 作为图片附件交给插件中选定的 Codex 模型。只启用 DeepSeek 或自定义 API 时，使用对应服务；模型必须支持图片。
- 若本次文字翻译因额度切换模型，后续识别与修复继续使用该服务。图片请求失败不自动转发至另一服务，人工修订保留。
- 修复换行符误报为缺失字形导致 PDF 生成中断的问题，保留多段译文的换行与数学表达。

安装 XPI 后重启 Zotero。本机 Codex 用户还需更新并重启同版 `paperweave-codex-proxy.mjs`；模型名称沿用插件中的配置，不需要另填图片服务。

离线路由、图片代理、取消/临时附件清理和 PDF 回归通过。已用合成图片实测本机 `gpt-6-luna`，并用已有译文缓存重排报错的 b89 段落，没有修改原缓存或重译整篇论文。尚未在 Zotero 内安装本版验收。

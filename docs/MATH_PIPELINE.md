# 数学表达：识别、保护、显示和复核

alpha.30 将数学处理作为贯穿抽取、翻译、修订和排版的一条流程。目标是保留原论文的数学信息，不从已压平的文本猜测公式语义。分数、上下标、重音、转置、数学字体、矩阵和多行布局不能由普通字符替换可靠恢复。

## 两种数学来源

| 来源 | 默认显示方式 | 修订方式 |
| --- | --- | --- |
| PDF 原文数学 | 从原 PDF 共享页面资源中裁出完整矢量区域，放入中文对应位置 | 保留原式；需要改写时，在译文中显式输入 LaTeX |
| 用户明确输入的 LaTeX | 离线 MathJax 转换为 PDF 矢量路径 | 修改 `\(...\)` 或 `\[...\]` 内的内容后保存 |

PDF 原式不经过模型重写，也不经过 Unicode 字符拼接。原式的分式线、上下标位置、帽子、粗体、花体和转置符号沿用 PDF 中实际存在的内容。原 PDF 若本身使用位图，保留其原有清晰度；插件不会把位图自动变成矢量公式。

## 1. 抽取完整数学对象

`mathRecognition.ts` 使用文本、叶节点样式和 SDT `textMap` 的逐字推进量，将完整表达式绑定到原文偏移、页码、区域、字号和基线。相连的分式、指数、上下标、函数和括号作为对象处理；括号外的逗号分开独立表达式和后续句子。独立公式继续使用原文区域，并保留同栏公式编号。

逐字坐标优先于逻辑行的包围框。SDT 可能给单个字形附上整行宽度，也可能把分子/分母误标为上标/下标；这些标签不能证明数学结构。缺少精确坐标、逐字数目不一致或区域明显异常时，标记为 `review`，不能宣称已识别正确。

网址、arXiv 引用、普通脚注及普通叙述有专门的排除规则。孤立斜体变量保留叶节点边界，避免抽取时与相邻英文粘连后丢失。识别仍是版面和规则驱动的候选检测，不是任意 PDF 的数学语义解析器。

## 2. 翻译保护和身份绑定

`provider.ts` 在术语和粗体处理之前，用一个不可变占位符保护一个完整公式。模型翻译周围文字，每个占位符必须出现一次。漏掉、重复或产生未知标记时执行有限重试；仍失败就拒绝保存该响应，保留已有译文和人工修订。

恢复占位符后，保存 `translationMathRefs`，记录译文范围对应哪个原文对象。模型调整语序时，公式仍能回到正确的位置。同式在原文多次出现时，每次出现有独立身份。API 不需要接收公式图片或原 PDF。

## 3. 旧缓存迁移

抽取版本为 8；alpha.31 的翻译规则版本为 8（alpha.30 为 7），项目格式仍为 schema 1。只有源文件身份、段落 ID、段落数量和规范化原文全部一致时，才更新本地版面元数据。缓存译文、人工修订和模型来源信息保留。保护协议见 [翻译保护与错误恢复](PROTECTION_PROTOCOL.md)。

没有显式绑定的旧译文按完整表达式匹配。先考虑最长表达式，避免短变量抢占长公式；支持已知旧版上下标表示、空白和有限标点差异。归一化后可能同时对应下标和指数等不同原式时，拒绝猜测。仅在排版视图恢复对应关系，不改写缓存中的中文。

## 4. 排版及安全回退

原文公式作为一个原子参与换行，两端对齐只调整公式之间及周围文字的间距，不拉伸公式内部。行高随分子、分母、上下标和多行对象变化。裁片使用 PDF 裁切路径，整页资源和字体共享，避免每个公式重复嵌入整套资源。

每个原式内部保留准确的相对坐标，包括没有文本节点的分式线和根号笔画。正文行末造成的物理换行根据字形顺序和位置跳变分组，再按原基线横向接回；不将它当成分式或矩阵。原文确实需要的行末连接符从 PDF 原区域保留，普通断词的软连字符不添加到公式中。无法避免裁入周围文字时进入复核。

无法证明公式对应、坐标不可靠，或原式需要缩小至一半以下才能放入右栏时，该段在右侧保留完整原文，并显示复核提示；中文和人工修订继续保存在项目中。生成结果会报告这类段落，工作台可用「公式 / 格式需复核」筛选。编辑了周围文字不等于确认公式正确。

用户明确修订为 LaTeX 后，手工表达优先。插件按显式 LaTeX 对象数量接受人工替换，不会验证其数学含义；用户需对照左侧原文确认每个公式。仅在模型旧译文里出现 LaTeX 不视为人工确认。无效 LaTeX 会给出错误，不会静默输出损坏的表达式。

## 5. 使用步骤

1. 安装 alpha.30 并重启 Zotero，打开对应论文的 PaperWeave 工作台。
2. 等待本地结构升级，查看「数学表达」计数和复核筛选。
3. 已有译文完整时，点击「翻译并生成 PDF」直接离线重排，不需要重新调用模型。
4. 需要修订公式时，选择段落，在译文中用 `\(\frac{a}{2}\)` 等明确写法替换对应旧公式，保存修订，再生成 PDF。
5. 核对右栏原式/手工公式、公式编号及所在段落。未完成段落仍需按原流程翻译；重新翻译单段会覆盖该段。

## 6. 验证范围和限制

离线回归覆盖分式、组合上下标、帽子与转置、梯度、求和及上下限、积分、根式、数学字母、科学计数法、比例、元组、矩阵及多行对象；另测占位符漏标/重复、语序调整、旧缓存歧义、坐标不精确、逻辑行宽度错误、脚注/网址排除、人工 LaTeX、原子换行、基线和过宽回退。

SpinQuant 使用完整 24 页原文和全部 107 段缓存译文重排，检查 119 处行内数学、5 个独立公式，生成 36 页对照 PDF；没有排除问题段落，没有模型请求。逐页缩略图检查整体分页，并放大检查公式密集页。

其他论文的抽取和缓存匹配审计用于检查通用边界，不代表这些论文已全部通过可视化验收。扫描件仍需 OCR；未检测到的公式、宿主错误分段、错误的原始坐标、跨栏复杂布局及任意模型译文都可能需要人工复核。本版尚未在 Zotero 内安装验收。

后续扩展应围绕同一数学对象接口：增加提取器/OCR 来源及置信依据、可视化区域修正、显式 LaTeX 绑定和对照验证；不要新增按某篇论文符号硬编码的替换规则。

# Roadmap

## Toward a stable 0.1

- Validate installation, startup/shutdown and menu hooks in a clean Zotero 10 profile.
- Validate SDT output on single-column, two-column, cross-page and nonstandard-font papers.
- Validate source glyph selection, image/table preservation, CJK embedding and long-paragraph pagination.
- Validate error recovery, local endpoints, API failures, cancellation, manual edits and project restore.
- Add source-page preview and explicit confirmation of uncertain block types.
- Record supported operating systems and host versions based on actual results.

## Reading and revision

- Reader selection → jump to paragraph editor.
- Paragraph anchors and a revision log linking output versions.
- A visual layout editor to split/merge regions and repair missed figure bounds.
- Side-by-side renderer using the same saved project.
- Glossary matching for normalized ligatures and carefully controlled variants.
- Better inline-math preservation and typography.
- Export CSV/XLSX and Markdown alongside JSON.

## Workflow and integration

- Opt-in project backup/sync across devices.
- Queue multiple papers with cost/progress estimates.
- OCR as an optional extractor.
- Provider capability discovery and endpoint profiles.
- Annotation migration with an explicit review of uncertain matches.
- Internationalized interface and additional target languages.

Open an issue before a large change so data-format and UI decisions remain coherent.

# 中文与数学表达的自动恢复闭环

alpha.50 的目标是保留可用中文，只修复不可靠的数学表达，并验证最终输出。原始 PDF 与既有人工修订不覆盖。

## 完成路径

- 先依据本地结构完整保留算法、图表、表格和图注。普通正文才进入自动核验。
- 现有中文具有精确的公式来源引用时，先对照原页核验中文、非公式数字和公式位置，避免整段反复重译。
- 坐标可靠的公式可以使用原 PDF 字形直接嵌入中文。每个候选裁切必须检查完整性、是否混入邻文、是否对应正确出现位置。紧裁切、局部隔离、扩大范围是有限的本地候选，不采用模型返回的任意坐标。
- 坐标被标为不可靠的公式不直接作为可展示截图。对于矩形区域难以隔离的数学表达，只识别目标公式；先验证 LaTeX 可解析与数字覆盖，再用另一次请求对照原图核验每个符号、上下标、运算、字体与顺序。通过后仅替换对应公式的显示，原中文不改写。
- 中文或来源对应确实有误时，使用原图进行带来源保护的翻译，再独立核验。未通过的新中文只保存为草稿，不覆盖旧译文。
- 普通 OCR 与 LaTeX 路径仍保留。最终确实无法可靠恢复的正文保留原文并明确统计，不显示为已完成中文；服务/登录/额度/磁盘/来源错误不能伪装成内容已通过。

## 断点与来源绑定

每批已通过的公式保存其来源矩形、图像指纹及中文版本。未通过的同图候选也记录，避免重复付费验证同一裁切。中断时保存已通过批次与候选中文；下次先继续恢复，再处理其他未完成段落。

进度绑定论文/附件、源文件摘要、原文、数学范围及几何、中文与粗体/公式引用、术语表、模型端点和模型名、原页图像。切换到不匹配的来源或配置时不能复用。人工编辑和重新采用识别会清除相关决定；升级仅保留精确兼容的证据。

可编辑项目 JSON 包含自动恢复记录及未核验草稿，导出时也包含这些论文文本。截图仍在本地私有缓存；API Key 不进入项目或 PDF。

## 输出检查

PDF 保存前检查所有应输出正文/公式区域是否出现、位置尺寸是否有效；采用混合显示的每个原公式引用恰好出现一次。数学作为完整对象排版，不把上下标或函数参数任意拆开。排版时新发现可修复问题，会回到自动修复后重新排版，最多两次，不先添加不完整附件。

自动核验依赖当前模型的判断，并不保证语义零错误。最多 24 个本地可定位的单区域公式进入该恢复路径；跨栏/跨页的复杂公式和错误正文分组仍由原有 OCR 路径处理，不能确认时明确保留原文。

## Codex 兼容

新增中文/原公式核验、带图片翻译和单公式再次核验任务，需更新 alpha.50 包内 `paperweave-codex-proxy.mjs` 并重启原代理。地址、模型及已保存 Key 不变。`/health` 的 `capabilities.formulaReview: 1` 表示支持本协议；旧代理不能处理这些新增任务，插件会保留进度并给出更新提示。DeepSeek 和自定义兼容图片 API 不需要本机代理。

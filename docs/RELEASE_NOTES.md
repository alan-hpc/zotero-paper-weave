# PaperWeave 0.1.0-alpha.13

## 本次更新

- 修复重新打开 Zotero 后右键翻译、工具菜单和阅读器入口消失：恢复首选附件时异步加载条目，单个条目读取失败不会中断其他记录与插件入口注册。
- 等待首选附件恢复完成后继续启动；停用时也使用异步清理。

- 修复后台阅读器暂停动画帧后，PDF 长时间卡在「保留原文区域」的问题。离屏导出使用 PDF.js 的打印渲染模式。
- 每个原文区域的单次处理最多 30 秒，失败时降低分辨率重试一次；两次失败会明确报错，保留已保存译文。
- 「取消」会中止正在等待的原文渲染。进度中显示源页、段落编号、当前子步骤和本区域用时。
- 修复完整论文排版时宋体字库缺少 `∼`、`⌈`、`⌉` 等符号的问题。按字符使用另一内置字库的字形，保留数学符号本身，不改写译文。
- 将进度提示移到主操作按钮下方，滚动时持续可见。
- 分别显示术语识别批次、已翻译段落、PDF 排版与保存阶段；术语阶段会明确提示正文尚未开始翻译。
- 显示任务用时、模型响应等待时间、120 秒超时限制和 HTTP 自动重试倒计时。
- 中英文正文两端对齐，段落末行左对齐，跨页后继续沿用段落对齐规则。
- 英文调整词间空格，中文调整字间空隙；英文单词与行内代码内部不拉伸。标题和原文保护区域保持自然排版。
- 中英文正文与英文技术术语统一使用思源宋体字库中的衬线字形，行内代码使用更纱等宽字体，缺字自动使用内置备用字形。
- 两种字库以 OFL 许可完整嵌入 PDF；术语保留规则继续逐篇生效。
- 调整中文换行，避免句号等结束标点单独出现在行首。
- 保留选定的 B 版：左英文 60%、右中文 40%，竖线分隔，逐段对齐。
- 修复 alpha.2 工作台停在“准备中”的初始化错误，以及安装包内字体读取错误。
- 图表、图注、公式以高清原文片段保留，避免原始裁剪页的隐藏文字干扰选中。
- 手工修订自动保存，本地生成新版本，并默认设为该论文优先打开的附件。原文和旧版批注保留。

## 安装

通过 Zotero → 工具 → 插件 → 齿轮 → 从文件安装 `.xpi`，然后重启 Zotero。
需要 Zotero 10；Alpha 预发布版需手动更新。首选附件记录保存在本机，停用插件后恢复默认顺序。

## 验证范围

通过 TypeScript 检查与离线回归检查，包括未加载的首选附件、单个记录失败、异步启动顺序、内置字体、混排、跨环境图像数据、分页、修订和首选附件生命周期。
在 macOS / Zotero 10.0.7 安装 alpha.13 后实际重启，确认文库右键翻译入口仍在，已有首选附件设置保留。
在 macOS / Zotero 10.0.7 上测试了官方 DeepSeek `deepseek-flash` 的两段翻译、独立词表、修订保存和新版首选附件。
进度提示通过本地模拟响应检查等待、重试、批次计数和结束状态，无新增验证模型调用。
这是小规模验证；整篇论文、其他操作系统与其他宿主版本仍需更多反馈。

图表片段内部的文字以图像保留；可在完整原文附录中检索。无 OCR、旋转页支持、批注迁移或项目自动同步。
模型调用向使用者配置的端点发送对应论文文本，可能产生费用。数据和字体许可说明见 README。

# DeepSeek 图片识别

从 PaperWeave **0.1.0-alpha.40** 起，可以把难以确定的正文/标题区域截图发送给 DeepSeek，识别英文和 LaTeX，再用于翻译。

## 配置

复用“模型与翻译偏好”中的 **DeepSeek 地址、模型和 Key**。启用 DeepSeek，模型填写 `deepseek-flash`，点击“保存全部设置”。不需要配置 Codex。

当前图片识别固定使用 DeepSeek 配置，不跟随正文翻译的服务优先级，也不会在图片请求失败或额度不足时把截图转发到别的服务。正文翻译仍按原来的优先级处理。

官方能力与图片请求格式见 [DeepSeek Vision 文档](https://api-docs.deepseek.com/guides/vision/)。模型支持图片，不代表每个公式都能识别正确，需要保留原图核对。

## 识别并修订一段

1. 右键打开论文的 PaperWeave 工作台，选中需要处理的正文段落。
2. 展开编辑区中的“**DeepSeek 图片识别与原图核对**”。
3. “**查看原文截图（本地）**”只读取本地 PDF，不调用 API；“**图片识别本段（DeepSeek）**”会上传该段截图并产生 API 用量。
4. 对照截图检查英文、变量、数字、公式上下标和编号。识别原文可以修改，点击“**保存识别修订**”保存；模型原始识别结果继续保留。
5. 点击“**采用识别结果（已核对）**”，再按需点击“重新翻译本段（覆盖）”，或直接修订中文。采用识别本身不会覆盖已有译文。
6. 点击“翻译并生成 PDF”生成新的阅读附件。已采用并与译文绑定的 LaTeX 在本机排版。

“**恢复本地识别**”可以切回原来的结构提取结果，识别记录仍在。若当前译文来自另一版识别，会提示重新核对或重译，避免混用版本。

## 处理多段

默认不会自动上传图片。需要时勾选 DeepSeek 配置中的“**重译需复核段落前，先用 DeepSeek 图片识别**”，然后点击“分步操作：词表与翻译”里的“**重译需复核段落（保留人工修订）**”。

- 只处理需复核的正文/标题；图表、算法、作者信息和人工修订译文跳过。
- 截图、识别和保存逐段进行。相同原文、截图与模型配置使用缓存；已人工修订的识别原文不会被自动重新识别覆盖。
- 结构检查通过且模型未报告疑问的结果，可以用于本次重译。**结构检查不是语义正确性的保证。**
- 不确定、数字/编号变化、区域类型改变或长度异常的结果保留待核对，不自动替换为正文。无效响应不覆盖旧结果；登录、额度和网络错误停止任务，已完成部分保留。
- 识别与翻译分别保存。只有新译文成功返回并通过公式/术语校验后，才替换该段自动译文。

## 数据与限制

原始 PDF、本地提取源文、段落 ID、坐标及旧附件保留。识别作为独立源文层，记录所用服务、模型、时间、来源绑定、问题说明和原始识别文本。每段额外保留最近 3 条被替换的识别记录；可通过导出项目保管。

截图以私有权限保存在 Zotero 数据目录的 `paperweave/vision/` 下，不会随项目 JSON 导出；JSON 会包含识别文本及其修订。API Key 仍只在 Zotero 凭据管理器中，不进入截图缓存、项目或 PDF。

每段最多 6 个区域；跨页/跨栏按既有矩形顺序分别截图，不上传整篇 PDF。每次请求有大小限制、取消与超时重试；无效截图不会发送。图片识别使用非思考模式，输出上限 8192 tokens。超长段落仍需要复核分段。

本版实现的是**疑难正文区域识别**，不把整张图或算法重新生成成中文，也不根据模型输出的坐标改变原文裁切。复杂公式、低清扫描件和错误分段仍可能识别失败；手工 LaTeX 和原图对照继续可用。

## 验证范围

已完成离线的多模态请求格式、PNG 裁切/缓存、原文绑定、识别结果校验、人工 OCR 修订、采用/恢复、批量重译、取消、错误与跨服务保护测试，并生成包含识别源文 LaTeX 的 PDF。测试使用模拟模型响应。

尚未在 Zotero 内安装本版验证真实 DeepSeek 请求，不能据此声称识别准确率或速度已改善。

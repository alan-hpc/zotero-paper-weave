# 当前模型自动识别与可选修订

alpha.49 支持自动检查、恢复和生成 PDF，不再要求用户逐段确认。原始 PDF、既有中文和人工修订保留。

## 使用

1. 复用「模型与翻译偏好」中启用的地址、模型和 Key，服务按自上而下的优先级选择。若本次文字翻译因额度切换服务，后续新建图片任务使用当前选定的服务。
2. 模型须支持图片输入；本机 Codex 需使用 alpha.43 或更新的配套代理。仅用 DeepSeek 或自定义兼容 API 也可。已知纯文字模型会在上传前拦截；具体图片能力以服务账户为准。
3. 勾选「生成 PDF 前，自动检查并修复疑难段落（无需人工确认）」，点击「翻译并生成 PDF」。图片上传默认关闭，勾选后使用对应服务的额度。

图片请求只发给选定服务，图片失败或额度不足时不会把截图转发到另一个服务。

## 自动处理规则

- 先修复物理区域归属：算法标题、Require/Ensure、循环、声明、阶段标签和所有步骤整组保留原文。阶段标签必须位于可信算法区域且有相邻步骤支持，普通叙述与人工分类仍是边界。
- 疑难正文先识别完整段落。核对区域类型、长度、数字出现次数、LaTeX 可解析性、数学样式及英文原文；格式失败提供具体公式与解析错误，带诊断重读一次。
- 第一轮仍失败时，用完整段落及最多 5 个由原文坐标确定的数学局部图继续识别。优先查看不明确和较复杂公式；细节图只是放大证据，不能作为第二份正文重复抄写。不会使用模型返回的坐标扩大裁剪。
- 两轮各最多 2 次内容响应；接口仍有自己的有限网络重试、超时和取消。识别缓存包含流程版本、模式、模型、截图与原文绑定；无细节可用时也不会将第二轮误当作第一轮缓存。
- 只有校验通过的正文/标题识别才自动采用，译文经过原有公式/术语保护校验后才替换旧译文。已采用和人工修订的识别优先复用。
- 最终仍不可靠的内容自动记为「保留原文」，在右栏对应位置嵌入完整原文区域，并注明原因及保留数量。中文、失败记录和识别历史留在项目中；不会清空失败标记或强行将不确定识别设为已确认。
- 该决定绑定论文、附件、源文件摘要、段落 ID、源文、坐标及正文分组，同时保存模型、时间、原因和图像指纹。反复生成不重复付费；来源或几何变化后不能复用旧决定。手动修订、采用识别或重译成功会清除对应决定。
- 取消、网络/登录/额度、磁盘、截图、来源混用和 PDF 生成错误会停止并保留进度，不能转换成自动原文保留。恢复服务后重新点击主按钮继续，无需清空缓存。

结构校验不能保证全部语义正确；自动流程的结束条件是正文检查通过，或内容明确按可信原文保留，不代表每段都有中文。

## 可选修订

自动流程不要求打开编辑区。需要修改时可选中段落，在工作台直接修改中文并保存，重新生成 PDF。原文图像仅用于保真展示，不能像正文一样直接改字。

也可展开「当前模型图片识别与可选修订」：「查看原文截图（本地）」不调用模型；「图片识别本段（当前模型）」上传目标区域；识别原文修改后可保存，再选择采用当前识别并重译。恢复本地识别可切回原始提取，记录保留。

## 数据与限制

每次最多 6 个区域、24 MB 图像请求。跨页/跨栏按既有矩形分别截图，不上传整篇 PDF。图片以私有权限保存在 Zotero 数据目录的 `paperweave/vision/`，不随项目 JSON 导出。JSON 包含源文、识别、中文、最近 3 条识别历史和自动处理记录，不包含 API Key。Key 保存在 Zotero 凭据管理器中。

扫描件需先 OCR；低清或复杂公式可能最终保留原图。算法、图表和图注不会重新生成成中文。可编辑项目不随 Zotero 自动同步，建议导出备份。
